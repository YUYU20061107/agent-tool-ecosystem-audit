# C1 家族级随机化分配协议 · 锁定件 v1.0（2026-11-18）

- 性质：C1 确证分析计划 §4 Gate 1「候选执行协议」的升格锁定件，依据 2026-11-18 23:06 PI 批复第 3 项（M2 声称限定锐零假设、分配协议由 Muse 升格锁定随签署包送审）。
- 适用范围：确证档 B/C 配对的臂分配与 Gate 1 家族级精确符号翻转检验的参考分布构造。**本件不授权任何运行**；确证档逐域信封另批。

## 1. 随机化单位与簇 ID

1. 随机化单位是**任务家族簇**，不是轨迹、模型、条件或 seed。
2. 每簇有唯一 `cluster_id`：由任务命名空间＋模板谱系标识构成（如 `browser/FAM03`、`tabular/F07`、GIS 家族同式），在确证清册冻结时登记成册。跨域、跨模型、跨条件共享同一模板谱系或同一生成依赖的任务归同一簇，**不得为增加簇数拆簇**，不得在见数据后改簇。

## 2. 配对槽位与分配位

1. 每个 B/C 配对由两个**可互换的配对槽位**（Slot-1／Slot-2）承载：同一任务快照、同一故障实例、同一模型版本与预算、隔离会话、独立恢复的等价初始状态、相同资源上限。槽位除臂标签外无系统差异；任一槽位被发现有系统差异，该家族全部配对停跑并报 PI，不得换槽续跑。
2. 每簇生成**一个独立公平随机位** `bit_f ∈ {0,1}`：`bit_f＝0` 时该簇全部配对 Slot-1＝B、Slot-2＝C；`bit_f＝1` 时 Slot-1＝C、Slot-2＝B。同一簇内所有配对共用同一位——这是 Gate 1 符号翻转参考分布（`2^F` 个符号向量）成立的设计基础。
3. 仅随机化执行启动次序**不构成**本协议的分配；启动次序可另行随机，但不得改动已分配的臂—槽位映射。

## 3. 随机位的生成与封存（可复算）

1. 清册冻结后、首条确证轨迹运行前，由 Muse 用操作系统 CSPRNG 生成 256 位主种子，写入只读种子封存件；其 SHA-256 承诺值先行登记进运行 manifest（只登记哈希、不登记种子本体）。
2. 每簇随机位由确定性函数导出：`bit_f ＝ LSB( HMAC-SHA256( seed, "C1-RAND-v1|" + cluster_id ) )`。同一种子与清册可逐位复算；种子在该波次锁库后随审计材料解封归档。
3. 种子**一波一换**，不得跨波次、跨域复用；清册变更（增删家族）后旧种子作废、重新生成并重新登记承诺值，且必须在任何新轨迹运行前完成。
4. 禁止重掷：已生成的分配位不得因任何运行结果、难度观感或中途统计而更改；基础设施失败的重跑沿用原位与原槽位映射，按 C1 冻结重试表记账。

## 4. 无干扰与盲法约束

1. 两槽位隔离运行：C 的谓词拒止信息、修复痕迹与中间状态不得以任何形式传给同对 B（反之亦然）；共享缓存、共享工件目录、共享会话一律禁用。
2. 分配登记表（cluster_id、bit、槽位映射）在运行期只对运行器可见；独立评分者臂盲判分，判分完成前不接触分配表与种子。

## 5. 与 Gate 1 检验的接口（口径锁定）

1. 家族统计量 `g_f`＝该簇内按 C1 预设权重求和的带符号配对差（`1(C=H) − 1(B=H)` 口径），`T＝Σ g_f`。
2. 参考分布：在第 2 节分配设计下，逐簇独立公平位给出 `2^F` 个等概率符号向量；`p ＝ Pr(T_flip ≤ T_obs)`，含同值与观察向量。有理权重先缩放为整数后对和的重数做精确计数（动态规划卷积），**不以有限抽样近似替代精确枚举**；簇数大时同样用精确计数，不改口径。
3. 声称边界（23:06 批复第 3 项）：上述精确性只支持**锐零假设**下的确证声称；不对弱零假设／平均风险差作正式确证声称。Delete-1-Family Jackknife 按 C1 §4 报告影响描述，不替代本检验、不投票。

## 6. 变更纪律

本件冻结后，簇定义、位生成函数、种子流程、槽位等价要求任一变更，须出变更单、经 PI 批准、版本号递增，并只对变更后尚未运行的波次生效；已运行波次的分配与分析口径不追溯更改。
