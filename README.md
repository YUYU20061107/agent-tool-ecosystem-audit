# Agent–Tool Ecosystem Audit — Public Materials

Materials accompanying the paper:

**Silent Failures at the Adaptation Seam: An Observational Audit of LLM Agent–Tool Ecosystems Across Four Domains, with a Registered Confirmatory Protocol**
Huangyu Rao, School of Remote Sensing Science and Technology, Sun Yat-sen University, Zhuhai, China
(arXiv identifier to be added on submission)

## Contents

- `docs/manuscript-v07.md` — manuscript text as submitted (v0.7, 2026-11-19).
- `docs/c1-randomization-protocol-locked-20261118.md` — locked randomisation protocol v1.0 for the registered confirmatory protocol (C1).
- `docs/browser-domain-master-ledger-frozen-20261118.md` — frozen post-adjudication master ledger of the browser-domain pilot (frozen 2026-11-18).
- `docs/o2-registration-effective-20261119.md` — registration record for the geospatial-domain snapshot set (35 files, SHA-256 manifest).
- `docs/f03-pi-final-approval-20261119.md` — principal-investigator final approval record for the 48-case acceptance review (F-03).
- `data/tabular-summary-counts.md` — summary counts of the tabular-domain pilot (independently recounted at protocol signing).

## Not included

Raw trajectories and per-item scoring files (browser-domain trajectories, tabular `verdicts.json` / `trajectory.jsonl`) contain full prompts and model responses and are **not** part of this release; they are held pending a separate redaction review. Credentials, authorisation artefacts, and connector materials are never included.
